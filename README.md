# DUY Portfolio Team — Premium One-Page Portfolio

**Where Logic Meets Creativity**

A fully responsive, production-ready portfolio website for DUY Portfolio Team — built with a premium dark UI inspired by Apple, Stripe, and Linear.

---

## Quick Start

1. Place your team photo at `assets/team/group-photo.jpg`
2. Open `index.html` in any modern browser
3. No build step required — pure HTML, CSS, JavaScript

## Design System

- **Font:** Inter (Google Fonts)
- **Background:** `#0a0a0f` deep dark
- **Accent:** `#6366f1` → `#8b5cf6` (indigo/violet gradient)
- **Secondary:** `#06b6d4` (cyan)
- **Glass cards:** `rgba(255,255,255,0.04)` + `backdrop-filter: blur(20px)`
- **Animations:** CSS keyframes + Intersection Observer
- **Breakpoints:** 1024px · 768px · 480px

---

## Features

- **Sticky navbar** with blur on scroll
- **Mobile hamburger menu**
- **Scroll reveal animations** (Intersection Observer)
- **Animated stat counters** (trigger on scroll)
- **Process diagram** with shimmer connector lines
- **Team card tilt** micro-interaction (mouse tracking)
- **Typing effect** on hero tagline
- **Image fallback** — glassmorphism gradient if photo missing
- **Contact form** with success state animation
- **Parallax** on hero background orbs
