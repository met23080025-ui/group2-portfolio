## Responsive Behavior

| Breakpoint | Change |
|-----------|--------|
| > 1024px | Full desktop layout — 2-col hero, 3-col expertise |
| ≤ 1024px | Single column hero, stats 2×2, expertise stacked |
| ≤ 768px | Hamburger nav, team 2-col, testimonials single-col |
| ≤ 480px | Team 1-col, stats 1-col, floating badges hidden |
